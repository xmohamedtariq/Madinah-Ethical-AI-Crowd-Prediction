# Before publishing this repository publicly

- The code archive is a personal research artifact. Make the repository **Private** initially if you have not confirmed the exact competition's **code-sharing rules**, especially if the competition is still open.
- Review https://www.kaggle.com/competitions/MDA-Ethical-AI-KAUST-Academy/rules and https://www.kaggle.com/competitions/MDA-Ethical-AI-KAUST-Academy/data. The rules page was not fully readable by the packaging workflow; the repository does not make any claim that public code sharing is expressly authorized.
- No official datasets, withheld labels, raw camera/video records, submission predictions, access credentials, or non-shareable model weights have been packaged.
- Inspect research scripts before publication for personal paths, possible unlicensed third-party code, and environment-specific references. Avoid committing any `.env` or Kaggle API `kaggle.json` file.
- A separate decision about code licensing is needed. This repository has **no `LICENSE` file**; do not assume it is licensed for reuse.
- If the competition requires public code also to be shared through an official Kaggle notebook or discussion, comply before publishing on GitHub.
