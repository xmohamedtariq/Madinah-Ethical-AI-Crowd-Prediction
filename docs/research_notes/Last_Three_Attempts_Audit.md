- **No numerical prediction differs by more than 0.0000000051 person.**
- Under the 0.000001-person absolute tolerance, **zero predictions differ**.
- **These are the same effective submission.** A different SHA-256 hash does not mean a new model.

The earlier `Champion_Final_Audit_Report.md` compared this production dry-run only with the older V13 fallback and found 2,792 changed values. That comparison is true but irrelevant for novelty relative to the *prior Kaggle champion*; the previous official-0.729 submission had already applied the same selected model. This is an auditing error, not evidence that the algorithm moved the public score by zero.

## New-camera alternative investigated and rejected for official submission

The production test contains **644 unseen-camera targets** I–M (555 Forecast, 89 Missing). Those 644 rows are unchanged from V13 fallback in both 0.729 submissions.

A separate *research-only* test mapped the same observed-minute availability patterns of new cameras to historical labelled camera signals, predicting 15 subsequent minutes using only data at or before the origin. Compared with persistence (the last observed count), smoothing toward the mean of the last three observations:

| Historical recording | All-pattern MAE change, smoothing minus persistence |
|---|---:|
| 20260904_1105 | -0.109 people per target (only 75 evaluated rows) |
| 20260911_1100 | -1.281 people per target (1,725 evaluated rows) |
| 20260912_1100 | **+2.218** people per target (2,100 evaluated rows) |

A lower-count, weakly blended, preconditioned variant improved the persistence proxy on those recordings, but **this comparison is not against actual V13 or Champion predictions on labelled unseen cameras**. The matched availability-pattern rows also repeat the same older camera values and are **not independent observations**. There is insufficient evidence to promote this experimental variant, and no new Kaggle file is recommended from it.
