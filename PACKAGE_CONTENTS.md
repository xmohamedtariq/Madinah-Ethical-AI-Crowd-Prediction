# Package contents and source scope

This GitHub-ready repository was curated from the files accessible in the shared conversation and personal file library.

- Saved selected source, all accompanying forecast, hidden, and missing `.py` modules.
- 28 historical modelling Python scripts recovered from the file library.
- Later V3-stage residual/gap/forecast research plus local validation interface scripts.
- 18 historical research reports and newer aggregate experiment outcomes.
- Saved local best-score metadata, production audit report, README files and reproducible production adapter.
- Windows PowerShell uploader, `.gitignore`, sample-independent CSV format validator, and a minimal syntax-check CI workflow.

## Deliberately excluded from GitHub ZIP

Official `train.csv`, `test.csv`, `sample_submission.csv`; personally saved production baselines and all competition prediction outputs; any file containing revealed target labels; raw photo/video; private credentials; local virtual environments; cached `.pyc`; temporary logs and backups. They should be kept in an **authorized private working directory** outside the repository.

## Not available to this packaging session

The full contents of the local Windows `Madinah-AI-Fresh` folder, and portions of the original `research_kit` (including benchmark/evaluator implementation). Accordingly this ZIP is a **curated repository** rather than a byte-for-byte backup of all local files.
